個人開發流程A personal development workflow, packaged as plugins

把一張需求從「想清楚」到「開 MR」的做法，拆成可獨立啟用的 skill 與 agent，依專案類型決定要啟用哪幾包。The path from a vague request to a merge request, split into small skills and agents. Each project type enables only the plugins it needs.

主流程 Main flowOne straight line; dashed items run only when a condition holds

主流程是一條直線。虛線的 skill 只在有條件時才叫：需求模糊、有設計稿、bug 卡住、高風險決定。複雜需求時，③ 的審查改走 ai-pair。The flow is linear. Dashed skills run conditionally: ambiguous request, a design file, a stuck bug, a high-risk decision. For complex work, ai-pair replaces build and review.

commit、push、開 MR 一律由人處理，agent 不自動執行。Committing, pushing and opening the MR are always done by a person; agents never do it automatically.
