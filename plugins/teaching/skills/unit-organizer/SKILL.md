# unit-organizer

把一份教材整理成「可以直接拿去設計一堂課」的結構化條目。

## 為什麼不用論文版的 TBRC

TBRC（論點／設計／發現／意義）是**讀者理解一份素材**的框架，優化目標是「讀完知道這篇說什麼」。

備課要的不是理解教材，是**設計一堂課**，優化目標是「學生學完會做什麼」。兩者資訊結構不同：
TBRC 缺「怎麼知道學會了」和「學生會卡在哪」，而這兩件事是備課的核心。

所以改用 **ODEP**，是逆向設計（Understanding by Design）的四層版本：

```
O  Objective   學完要會什麼    ← 先定這個
D  Diagnosis   學生帶著什麼來  ← 再查起點與已知迷思
E  Evidence    怎麼知道學會了  ← 然後訂評量
P  Plan        怎麼教          ← 最後才排活動
```

**順序即設計順序。** 大多數備課的失敗是反著做：先想要講什麼（P），最後才想怎麼考（E），
結果目標、活動、評量三邊對不上。ODEP 的欄位順序就是在強制逆向設計。

比原始 UbD 三階段多出的 **D 層**，是為了承接跨學期累積的學生迷思——這是本 kit 的核心資產，
必須在模板層就有固定位置，不能塞附錄。

## 使用方式（純對話）

```
把課本第三章整理成單元條目
整理 raw/ 裡還沒處理的教材
行銷管理第三單元整理一下
```

## 執行步驟

### 1. 讀取素材

依格式套 `AGENTS.md` 的讀取規則。`.pptx/.docx/.xlsx` 要讀 `raw/converted/` 的轉換產物。

⚠️ 若轉換產物標有「順序可能錯亂」，先確認段落邏輯是否合理，必要時對照原檔。

### 2. 判斷 unit_key

已有 → 沿用（**這是跨學期累積的關鍵，絕不因為新學期就換 key**）。
沒有 → 問教師：「這是哪門課的第幾單元？」

### 3. 產出 O 層（先做這層）

**Big idea**：一句話。「學完這個單元，學生能……」

寫法檢查：
- ❌ 「介紹市場區隔的概念」← 這是教師要做的事，不是學生能做的事
- ✅ 「能用市場區隔的三個準則判斷一個真實市場該不該切」

**必問問題** 2-3 個。特徵：沒有標準答案、學生會想辯論。不是考題。

**學習目標** 3-4 條，動詞**必須**取自 `refs/bloom-verbs-zh.md`。

🛑 出現「了解」「熟悉」「認識」「掌握」→ 重寫。這些無法觀察、無法評量。

### 4. 產出 D 層

**先備知識**：需要什麼、**不需要什麼**（後者同樣重要，避免自己講太深）。

**已知學生迷思**：搜尋 `wiki/misconceptions/` 中 tag 相符（同 `course/` 或同 `topic/`）的條目，
以 wikilink 掛進來。

第一次整理某單元時這裡通常是空的——正常。上完一輪、跑過 `misconception-miner` 之後會長出來。
空的時候明確寫「（尚無累積，第一輪教學後由 misconception-miner 補上）」，不要留白讓人以為漏了。

**預估認知負荷**：低／中／高 + 降負荷策略。判斷依據：新概念數量、抽象程度、是否需要計算。

### 5. 產出 E 層

**形成性**（課中即時知道懂沒懂）＋ **總結性**（課後）＋ **表現指標**。

🛑 **對齊檢查**：E 層的評量方式必須與 O 層的 Bloom 層次相符。

| O 層寫 | E 層不能只有 |
|---|---|
| 能分析 | 選擇題 |
| 能評鑑 | 簡答題 |
| 能創造 | 任何紙筆測驗 |

對不上就當場指出，讓教師選擇改 O 還是改 E。這是 `objective-alignment-check` 的前置。

### 6. 產出 P 層

時間表（分鐘級）＋ 素材對應 ＋ 鷹架（弱／強兩檔）＋ 風險備案。

**時間總和必須等於課堂長度。** 不要規劃 75 分鐘的內容塞進 60 分鐘。

### 7. 關鍵內容摘錄

每條**必須**標來源頁碼與事實標籤：

```
1. `[課本 p.78]` 市場區隔的四個變數 `[已核對]`
2. `[講義 p.3]` 補充的本土案例 `[教師補充]`
3. `[影片 12:30]` 講者提到的數據 `[待查證]`
```

| 標籤 | 意思 | 限制 |
|------|------|------|
| `[已核對]` | 教師或 AI 已對照原文確認 | 可用 |
| `[教師補充]` | 教師自己的知識，非教材內容 | 可用 |
| `[待查證]` | 來源不明、數據無法確認、自動字幕可能有誤 | 🛑 **不得進投影片或考題** |

自動字幕（`transcript_quality: auto`）來的內容**預設全標 `[待查證]`**。

### 8. 指派 tag 與更新 INDEX

依 `refs/tag-taxonomy.md`，3-5 個：課程 1 + 主題 1-2 + Bloom 1 + 類型 1（+ 層級）。

更新 `wiki/INDEX.md` 三個分面清單（按課程／按主題／迷思庫）。

### 9. 標記來源已處理

`raw/fixed/` → `touch <檔名>.processed`
其他 → frontmatter `status: processed`

## 不要做的事

- **不要幫教師決定教法**。A 層的角度選擇是教師的判斷，AI 只列選項
- **不要編造頁碼**。找不到頁碼就寫 `[頁碼待補]`，不要猜
- **不要覆寫「教師備註」段落**。那是教師自己的區域
- **不要因為新學期而建新條目**。同一單元永遠同一個檔案，累積才有價值
