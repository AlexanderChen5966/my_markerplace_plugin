# objective-alignment-check

備課最常出錯、也最難自己看出來的地方：**目標、活動、評量三邊對不上。**

論文版有 `alignment-check`（檢查 wiki 段落歸屬）。教學版把它升級成教學設計的核心檢查——
這是本 kit 相對於論文版價值提升最大的一個 skill。

## 典型的三種對不上

| 症狀 | 實際發生的事 |
|------|------------|
| **教了沒考** | 花 3 週講的內容考卷完全沒出現。學生下學期就學會「不用聽那部分」|
| **考了沒教** | 考卷考了分析題，但課堂只講過定義。學生覺得被陰 |
| **層次錯位** | 目標寫「能評鑑」，考卷全是選擇題。宣稱培養高階思考，實際在考背誦 |

第三種最隱蔽，因為每一份文件單獨看都沒問題。

## 使用方式（純對話）

```
第三單元的目標活動評量對得上嗎
對齊檢查 MKT101-U03
期中考跟我教的內容對得上嗎
這學期整體檢查一次
```

## 檢查範圍

| 層級 | 比對什麼 |
|------|---------|
| 單元 | ODEP 的 O ↔ P ↔ E 三層 |
| 產出 | ODEP 的 O ↔ 教案 ↔ 投影片 ↔ rubric ↔ 題庫 |
| 課程 | 全學期目標 ↔ 各單元 ↔ 期中期末配分 |

## 五道檢查

### 檢查一：Bloom 層次相符

每個學習目標的 Bloom 層次，必須有**相符層次**的活動與評量。

| O 層宣告 | 活動至少要有 | 評量至少要有 |
|---------|------------|------------|
| 記憶 | 練習、複誦 | 選擇、填空 |
| 理解 | 舉例、改寫 | 簡答、說明題 |
| 應用 | 實作、計算練習 | 計算題、案例套用 |
| 分析 | 案例判讀、找錯 | 案例分析題 |
| 評鑑 | 方案比較、辯論 | 申論、方案評估 |
| 創造 | 專題、設計 | 專題作品 |

**判定**：

```
🔴 MISALIGNED

目標 3：（Bloom: 評鑑）能評估兩個區隔方案並提出取捨理由

  活動：✓ 有（30-50 分的小組取捨討論）
  評量：❌ 沒有
        小考 5 題全是選擇題（記憶 2 / 理解 2 / 應用 1）
        選擇題無法評量「提出取捨理由」

影響：你花了 20 分鐘課堂時間帶學生做取捨，但考試不考。
      學生會學到「那段可以不用認真」。

兩個選擇：
  (a) 小考加一題申論（建議 20 分），細目表要重算
  (b) 把目標 3 降級成「能說出兩個方案的差異」（Bloom: 理解）

我建議 (a)——你既然花了 20 分鐘教，就值得考。
```

### 檢查二：目標覆蓋率

每個學習目標都必須：**被教到**（P 層有對應環節）＋ **被考到**（E 層有對應評量）。

```
目標覆蓋矩陣：

| 目標 | Bloom | 教到 | 考到 | 判定 |
|------|-------|:---:|:---:|------|
| 1 能說明四個變數 | 理解 | ✓ 10-30分 | ✓ Q1,Q2 | ✓ |
| 2 能判讀區隔基礎 | 分析 | ✓ 30-50分 | ✓ Q3 | ✓ |
| 3 能評估方案取捨 | 評鑑 | ✓ 30-50分 | ❌ | 🔴 |
```

### 檢查三：時間與配分成比例

課堂投入時間佔比 vs 評量配分佔比，差距 > 20 個百分點就標記。

```
⚠️ 比例失衡：

  主題 A：課堂 15%（9 分鐘）→ 配分 35%
  主題 B：課堂 50%（30 分鐘）→ 配分 20%

  你花最多時間教 B，但考最多 A。
  學生下次會怎麼準備？他們會發現「聽課不如背 A」。
```

### 檢查四：術語一致性 ★ 商管特別重要

比對 `unit-synthesis` 的 A 層「教師選擇」與實際產出的術語使用。

```
🔴 術語混用：

  合成條目 A 層選定：課本 A 的講法（4P 架構）
  但實際產出：
    - 投影片 p.7 用「4C」（顧客成本、便利性…）
    - 小考 Q4 題幹用「4P」
    - 教案講述環節混用兩套

影響：學生看投影片學 4C，考試考 4P，會以為是兩套不同的東西。
      這是商管課最常見的混亂來源。

建議：統一成 4P（你在合成條目選的），投影片 p.7 改寫。
      若要教兩套的對應關係，那要單獨一張投影片明講「這兩套是同一件事的不同視角」。
```

### 檢查五：迷思是否被主動處理

D 層掛的已知迷思，是否在 P 層有對應的主動點破？

```
⚠️ 迷思未處理：

  D 層掛了 2 個迷思，但教案的講述環節只主動點破 1 個。
  [[misconception-MKT101-越細越好]] 沒有被處理。

  這個迷思上學期 42% 的學生犯過。建議在講「區隔變數」時
  加一句「切得越細不代表越精準，因為每個區隔都有服務成本」。
```

## 判定等級

| 判定 | 條件 |
|------|------|
| ✅ **ALIGNED** | 五道全過 |
| ⚠️ **PARTIAL** | 檢查三、五有問題（比例失衡、迷思未處理）——可以上課，但建議調整 |
| 🔴 **MISALIGNED** | 檢查一、二、四有問題（層次錯位、目標未覆蓋、術語混用）——建議改完再上 |

**advisory 不阻斷**：本 skill 不阻止教師上課。它的作用是讓對不上的地方被看見。
真正阻斷的只有 `privacy-guard` 與人工審核閘門。

## 不要做的事

- **不要自動修改**。對齊問題的解法有兩個方向（改目標或改評量），該由教師選
- **不要只報「有問題」**。要說出影響（學生會怎麼反應），教師才會想改
- **不要把 PARTIAL 當成過關**。比例失衡是學生「學會不聽課」的主因
- **不要阻斷上課**。這是 advisory
