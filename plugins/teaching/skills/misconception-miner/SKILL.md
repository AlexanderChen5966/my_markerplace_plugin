# misconception-miner

**這是本 kit 最有差異化價值的 skill。** 論文版沒有對位物。

一般 AI 備課工具做的是「幫你生成教材」——用一次就丟。這個 skill 做的是
**把每一輪教學的學生真實反應變成跨學期累積的資產**：教到第三年，你的 `misconceptions/`
會知道這個單元學生會在哪五個地方卡住，而這是任何現成教材都不會告訴你的。

## 前置閘門

🛑 學生作答必須先過 `privacy-guard` 去識別化。未去識別化不處理。

## 使用方式（純對話）

```
這批作業學生卡在哪
分析第三單元小考的作答
misconception-miner MKT101-U03
這學期期中考結果看一下
```

輸入可以是：去識別化的作業文本、考卷作答分布、選擇題選項統計、課堂觀察筆記。

## 執行步驟

### 1. 找出錯誤模式（不是列出所有錯誤）

**目標是模式，不是清單。** AI 傾向把每個學生的每個錯誤都列出來——那沒有用。

篩選標準：**≥ 30% 的學生犯同一個錯，或 ≥ 3 人錯在完全相同的地方。**

低於門檻的錯誤歸「個別指導」，不進迷思庫。

```
12 份作業，找到 3 個模式：

【模式 1】8/12 人（67%）把「區隔」寫成「分類」
  典型表述：「將顧客依年齡分成三群」——只做了分類，沒討論可觸及性與獲利性
  → 符合已知迷思 [[misconception-MKT101-區隔等於分類]]，更新出現學期

【模式 2】5/12 人（42%）認為區隔越細越精準
  典型表述：「應進一步細分為 8 個子群以提升精準度」
  → 新迷思，建立條目

【模式 3】2/12 人（17%）混用 4P 與 4C 術語
  → 未達門檻，歸個別指導。但要注意：這可能是 unit-synthesis 的 A 層
     沒有選定講法造成的，值得檢查
```

模式 3 的處理方式是重點：**未達門檻的錯誤若指向系統性原因（教材術語不一致），仍要標出來。**

### 2. 判斷：教法問題還是題目問題

```
學生錯得有規律嗎？

  多數學生錯在同一處、錯法一致
    → 【教法問題】
    → 建 misconceptions/ 條目 + 寫進 teaching-lessons/
    → 這是你要改教法，不是學生不認真

  錯法分散、無規律
    → 【題目問題】（題幹不清、選項可雙解、範圍超出教過的內容）
    → 交給 quiz-generator 修題，不進迷思庫
```

**這個區分是整個 skill 的核心判斷。** 把教法問題誤判成題目問題，就會一直修題目而不改教法，
明年同樣的事再發生一次。

### 3. 建立或更新迷思條目

`wiki/misconceptions/misconception-<課號>-<簡短描述>.md`

```markdown
---
title: 學生把「市場區隔」等同於「顧客分類」
misconception_id: misconception-MKT101-區隔等於分類
unit_keys: [MKT101-U03]
course: 行銷管理
type: misconception
status: processed
first_seen: 2025S
occurrences: [2025S, 2025F, 2026S, 2026F]   # ★ 每次出現就 append
frequency: 4                                  # 出現學期數
severity: high                                # high | medium | low
tags: [course/marketing, topic/segmentation, type/misconception]
---

## 迷思內容

學生認為市場區隔就是「把顧客依某個變數分群」，忽略了區隔必須同時滿足
可辨識、可觸及、有獲利性、反應有差異這幾個條件。

## 典型表述

- 「將顧客依年齡分成 18-25、26-40、41+ 三群」（只做了分類）
- 「依所得高低區隔為高中低三個市場」（沒問這三群買不買）

## 為什麼會這樣想

「區隔」字面上就是「分開」，加上課本先講變數分類、後講有效性條件，
學生讀到前半段就以為講完了。這是**教材編排造成的**，不是學生粗心。

## 診斷方式

- 選擇題誘答：MKT101-U03 小考 Q1 選項 (B)
- 作業徵兆：分群後沒有討論「這群人找得到嗎、會付錢嗎」

## 有效的教法（累積中）

| 學期 | 做法 | 效果 |
|------|------|------|
| 2025F | 講完變數後補一句「分完要問三個問題」 | 略有改善，仍 60% 犯錯 |
| 2026S | 改用「失敗案例反推」：先給一個切錯的市場 | 降到 42% ✓ |
| 2026F | 案例 + 一分鐘紙條當場檢核 | 待觀察 |

## 相關

- 單元條目：[[MKT101-U03]]
- 合成條目：[[市場區隔]]（V 層）
- 教學反思：[[teaching-lesson-2026S-區隔案例反推]]
```

**「有效的教法」表格是這個檔案的核心。** 它記錄的是「你試過什麼、有沒有用」，
教到第三年就會知道哪一招真的管用。

### 4. 反覆出現時觸發教法檢討

`frequency ≥ 3` 時主動提出：

```
⚠️ [[misconception-MKT101-區隔等於分類]] 已經連續 4 個學期出現。

連續三次以上代表這不是學生的問題，是教法或教材編排的問題。

從你的紀錄看，2026S 改用「失敗案例反推」有效（60% → 42%），
但還是偏高。建議這學期試：

1. 把「有效區隔的四條件」提到變數分類【之前】講
   （目前課本順序是先分類後條件，學生讀到一半就停了）
2. 在 ODEP 的 P 層把這個順序調整記下來
3. 考題誘答保留 (B)，下次考完就知道有沒有改善

要我更新 MKT101-U03 的 P 層嗎？
```

### 5. 回寫 ODEP 的 D 層

新建或更新迷思條目後，把 wikilink 掛回對應 `wiki/unit-notes/<unit_key>.md` 的 D 層。

**這一步不可省略**——迷思庫的價值在於下次備課時自動出現在眼前，而不是躺在資料夾裡等人想起來。


## 不要做的事

- **不要列出所有錯誤**。沒達到模式門檻的歸個別指導
- **不要把題目問題當教法問題**（反之亦然）。這個判斷錯了會浪費一整年
- **不要指涉個別學生**。條目只記模式與比例，不記「學生C 錯了」
- **不要每學期建新條目**。同一個迷思永遠同一個檔案，`occurrences` append 上去。
  建新檔就毀掉 frequency 這個最重要的訊號
- **不要說「學生不認真」**。反覆出現的迷思是教法訊號，不是態度問題
